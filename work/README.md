# work: the server

The part that runs on facilio.work. It has no screens. The app calls it for everything that needs a database, the AI services, the Microsoft connection or a decision about who may see what.

* `server/api.mjs`: the one server function. Every route, every check of who may do what, and the tools the Claude connector offers.
* `server/_*.mjs`: the same server split by topic (AI, jobs for Claude, tasks, mail, contract reading, questions, notifications). Each file starts with a comment that says what it is for.
* `src/workapi.js`: the small link the pages use to call the server.
* `work.json`: the list of tools that Otto (the Teams bot) and the Claude connector may call.

Rules: keys and secrets never leave the server; a person only sees the projects they belong to; AI answers are always drafts until a person approves them.
