## What needs your decision

1. Set the secret `platform_owner` (the owner's Facilio email) in the secrets portal, then ask for the code value to be removed.
2. Web push and scheduled Teams reminders cannot be delivered reliably on this platform. Do you want "evaluate on open" reminders, or an external scheduler?
3. The prompt's nine-stage lifecycle differs from the seven in the code. Decide which names to keep before the tracker is rebuilt.
